# Grading system

| Minimum | Grade | Remark |
|---:|:---:|---|
| 80 | A | Excellent |
| 70 | B | Very Good |
| 60 | C | Good |
| 50 | D | Pass |
| 0 | F | Needs Improvement |

These are project defaults, not universal academic rules. Bands must be unique, valid, and include a band beginning at zero. Thresholds are inclusive: 80 is A; 79.99 is B.
