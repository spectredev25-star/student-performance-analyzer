# Installation

Python 3.10+: create a virtual environment in `python/`, activate it, then run `python -m pip install -e ".[dev]"`. On Windows PowerShell: `.venv\Scripts\Activate.ps1`.

Node.js 20+: run `npm install`, `npm test`, and `npm run build` in `javascript/`.

For PostgreSQL, apply the migration and seed SQL using `psql` or a database GUI.
